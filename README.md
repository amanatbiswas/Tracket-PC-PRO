**Tracket PC Pro** is a high-performance, standalone desktop application designed for seamless video object tracking and environmental stabilization. Built with C#, WinUI 3, and OpenCV, it features a sleek, hardware-accelerated "Phonk" inspired user interface.

## ✨ Features
*   **🔍 CSRT Object Tracking:** High-accuracy manual bounding-box tracking.
*   **🎥 Environment Stabilization:** Dot-cloud feature tracking for stable video output.
*   **🎯 Center Anchor Lock:** Automatically crops and anchors the moving subject to the center of the frame.
*   **⚡ Hardware Accelerated UI:** Built on the modern Windows App SDK (WinUI 3) for smooth, fluid liquid-glass visuals.
*   **💾 Robust Export Engine:** Bulletproof rendering pipeline with automatic even-dimension scaling and AVI/MP4V fallback support.
